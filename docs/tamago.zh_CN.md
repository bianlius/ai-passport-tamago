# AI Passport 上的 Tama-Go

此应用使用 T7Emu 的 CPU 和外设模拟核心运行用户提供的 640 KiB Tama-Go ROM，
并实现了 Passport 专用界面、按键映射、音频及基于 NVS 的 EEPROM 和会话存档。
原有硬件测试示例源码保留作为参考，但不会编入本应用。

## 按键

| Passport 按键 | Tama-Go 按键 |
| --- | --- |
| UP | A |
| DOWN | B |
| OK | C |

游戏仅由 Passport 的实体按键操作，屏幕上不显示虚拟按键。按下和松开事件都会传给
模拟器。屏幕横向使用（320 × 240），游戏 LCD 上下各有五个 24 × 24 图标，亮度跟随
Tama-Go 显示内存中的图标状态。图标统一选自 [Lucide Icons](https://lucide.dev/icons)：
游戏 LCD 的每个原生像素绘成 5 × 5 方格，边缘用一个屏幕像素的低对比度细线表现，
既能看清像素格，也不会把画面轮廓割断。
LCD 采用柔和的灰白四阶配色，不使用刺眼的纯白。
上排依次表示信息、食物、厕所／冲水、门、人物配件；下排依次表示训练、医疗、红外通信、
相册、提醒。含义和排列参照 [Bandai Tama-Go 快速指南](https://manuals.plus/m/a3d3256736d3d52c1ec7eca6353801f04e9d84f6b2cfcaf6490c914fed6868f3)。
SVG 与像素图来源、许可及转换方式记录在
[`assets/images/tamago_lucide`](../assets/images/tamago_lucide)。
在首次设置生日、名字及等待孵化时，游戏尚未开放上下图标。此时按 UP（A）选择
数值，按 DOWN（B）确认；进入宠物主画面后，UP（A）才用于切换图标。

长按实体 UP 约 1.5 秒打开设置界面。松开 UP 后，用 UP／DOWN 选择音量、亮度、
人物配件或返回游戏，按 OK 进入。音量和亮度都显示为百分比；进入调整界面后，
UP／DOWN 每次调整 5 个百分点，并实时预览，按 OK 保存到 NVS 并返回设置列表。
音量范围为 0–100%；亮度范围为 5–100%，避免屏幕全黑后无法操作。

人物配件界面只列出已导入设备的角色，以及“无配件”“文件传输”和“返回设置”。
用 UP／DOWN 选择配件，短按 OK 选用并返回设置；长按 OK 约 1.5 秒可随时
返回设置，不更换配件。选择“文件传输”后短按 OK 可进入无线／USB 方式选择页；
选择“返回设置”后短按 OK 也可退出。尚未导入的配件不会显示；一个都未导入时，
仍可选择“无配件”“文件传输”或“返回设置”。
旧配件会立即取下，新配件约 2.5 秒后插入，供 Tama-Go 游戏识别。选择保存在
NVS 中，重启后会恢复。菜单只显示文字，不在游戏画面添加虚拟按钮。菜单标题、
提示和“无配件”项均为简体中文；已导入角色按“中文显示名 英文原名”显示。
中文显示名是便于识别的界面译名，不代表官方译名。

## 导入 ROM

模拟器固件不包含游戏 ROM 或人物配件 ROM。首次开机若没有主游戏 ROM，设备会
显示“未检测到游戏 ROM”“请选择传输方式导入”。用 UP／DOWN 选“无线传输”
或“USB 有线传输”，按 OK
确认；已有主游戏 ROM 时还可选“开始游戏”。选择无线后，设备才启动热点并显示
Wi-Fi 二维码。用手机扫描并连接设备热点，手机通常会提示打开本地传输页；
若未自动打开，请按设备的 UP 切换成网页地址二维码再扫一次，也可以保持连接热点
并在浏览器访问 `http://192.168.4.1/`。
无线网页只使用常见的文件选择和网页传输功能，可用手机或电脑的常用浏览器。
若系统自动弹出的简易联网窗口无法选择 ROM 文件或下载存档，请保持连接设备热点，
改用 Safari、Chrome 等完整浏览器打开该地址。
先上传自有的 655,360 字节 Tama-Go 主游戏转储文件，再使用唯一的“人物配件 ROM”
入口选择一个或多个配件文件。网页读取 ROM 头部的内部编号，自动识别人物并分配槽位；
同一批中重复的人物和无法识别的文件会在上传前被拒绝。前 6 个配件文件每个为
349,536 字节，后 6 个每个为 524,288 字节。设备在写入后也会检查内部编号、
文件大小和 Flash 内容，再把配件标记为可用。页面只显示一个配件上传区及已导入摘要。
导入主游戏后点击“完成并启动游戏”。游戏中长按 UP，进入“人物配件”，选择“文件传输”，可再次进入
传输方式选择页；切换前会保存当前宠物会话。无线界面按 DOWN、有线界面按 UP
可返回选择页。设备在选择方式之前不会启动热点或 USB 传输服务。

有线传输时，用可传数据的 USB 线把 Passport 连接到电脑，在设备上选择
“USB 有线传输”。将单文件 [`tools/TamaGo-USB.html`](../tools/TamaGo-USB.html)
复制到连接设备的电脑，用支持 [Web Serial](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API)
的浏览器打开，推荐桌面版 Chrome 或 Edge；点击“连接设备”并在浏览器
弹出的串口列表中选择当前连接的 AI Passport。串口名称和 USB 编号可能因设备而异；
网页会在连接后验证 Tama-Go 传输协议。网页直接通过 USB 串口
导入 ROM、导出或导入存档；无需 Python、安装依赖、运行本地服务器或连接互联网。
Windows、macOS 和 Linux 的桌面版 Chrome/Edge 可按此流程使用；浏览器及操作系统
可能要求授予 USB 串口访问权限。其他浏览器能否使用以网页的 Web Serial 检测为准；
手机和平板建议使用设备的无线传输页。配件文件按选择顺序逐个导入，看到“导入成功”前请勿拔线；
最后点击“完成并启动游戏”。导入主游戏后也可在设备上按 OK 启动。

旧版电脑桥接工具 `tools/tamago_usb_transfer.py` 及 Mac 启动器
`tools/TamaGo-USB.command` 仍可备用。桥接工具需要 Python 和 `pyserial`，会在
`http://127.0.0.1:8765/` 提供本机网页；它与浏览器直连页不能同时占用设备串口。
旧版桥接工具只按已知 USB 编号自动查找设备；其他编号可运行
`python3 tools/tamago_usb_transfer.py --port PORT` 指定串口。

## 存档备份与恢复

在设置中进入“人物配件”并选择“文件传输”，使用手机无线网页或电脑 USB 网页，点击“导出存档”即可
下载 `.tgsave` 文件。备份包含模拟的 4 KiB EEPROM，以及存在时的最新会话快照；
不包含游戏／配件 ROM、热点密码、音量或亮度设置。

恢复时先导入与存档匹配的主游戏 ROM，再选择 `.tgsave` 文件并点击“导入存档”。
网页会确认替换现有宠物存档；设备会先检查文件格式、CRC 和主游戏 ROM 是否匹配，
再写入 NVS。导入期间保持设备通电，完成后点击“完成并启动游戏”。替换前建议先
导出当前存档，以便写入中断后重试恢复。备份保存在下载它的手机或电脑，不会由
设备上传到云端。

应用分区为 2 MiB；ROM 位于从 `0x210000` 开始的独立数据分区，宠物存档所在
NVS 分区仍从 `0x9000` 开始。分区布局相同的应用分区更新可以保留这些数据；
整片擦除或不兼容的分区变更可能清除它们。12 个人物配件文件均为可选。
ROM 只保存在用户自己的设备上，不纳入 Git 或固件镜像。

使用 ESP-IDF 5.5.3 运行 `./tools/validate.sh`。开发者如有本地主游戏文件，
可以运行可选的主机冒烟测试 `./tools/test_tamago_core.sh`。

导入的 `main/t7_core` 来自 Paramix Studio 的 T7Emu，适用该项目的 GPL-3.0
或更新版本许可；许可和上游声明存于同一目录。上游项目注明模拟器最初来自
asterick 以 BSD 许可发布的 `tamago`。不要将 ROM 随源码提交或发布。

## 存档与当前限制

模拟的 4 KiB EEPROM 保存在 NVS 中，会话快照每分钟保存一次。突然断电可能
丢失最多一分钟的内存进度。快照与导入的主游戏 ROM 哈希绑定，更换 ROM 后会建立新会话。
快照版本 2 保存 6502 的实时状态标志；旧版快照仍可读取，并在恢复时重新开启
中断，避免游戏画面停住且按键无效。
本项目未确认 Passport 具有断电持续走时的时钟来源，因此完全关机期间宠物时间
暂停。尚未逐一检查所有音效及配件组合。在已测试的 Passport 宠物画面中，
完成空转循环与帧调度优化后，连续四组各 200 帧的完整帧平均耗时为
49.95–50.00 毫秒，达到游戏每帧 50 毫秒的目标。按键和菜单操作期间，另外四组
平均也约为 50.00 毫秒。设备主人确认动画更顺畅，按键和声音正常。
