Tama-Go USB 有线传输

用 USB 数据线连接 AI Passport，在设备上选择“USB 有线传输”，然后点击“连接设备”。人物配件可一次选择多个文件，网页会按 ROM 内部编号自动识别。

有线传输需要浏览器支持 Web Serial，推荐电脑上的 Chrome 或 Edge。请在浏览器的串口列表中选择当前连接的 AI Passport；串口名称和 USB 编号可能因设备而异。连接后网页会验证传输协议。本页在电脑本地运行，文件不会上传到互联网。
